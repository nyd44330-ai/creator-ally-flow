
## خطة البناء التدريجي – تطبيق التسويق بالمؤثرين

سأبني التطبيق صفحة بصفحة بناءً على التصاميم المرفقة (RTL عربي، تصميم نظيف بأزرق ملكي + لمسات بنفسجية فاتحة، خلفية بيضاء/رمادي فاتح جداً، خط Cairo/Tajawal).

### الخطوة 1 (الآن): الصفحة الرئيسية — اكتشف المؤثرين
الصفحة الأولى من الصورة الأولى. واجهة فقط ببيانات وهمية، بدون باك-إند بعد.

**المحتوى:**
- Header: زر إشعارات + عنوان "اكتشف المؤثرين" + زر فلاتر
- شريط بحث "ابحث عن مؤثر أو مجال..."
- شريط فلاتر أفقي: الأعلى تقييماً، الموقع، الفئة، المنصة + أيقونة فلتر
- قسم "مؤثرون مميزون" + رابط "عرض الكل" → 3 بطاقات أفقية بصور كبيرة، اسم، فئة، تقييم
- قسم "جميع المؤثرين" → بطاقات عمودية (صورة دائرية، اسم موثّق، فئة، إحصائيات TikTok/Instagram/YouTube، نطاق سعر، شرائح خدمات، زر "عرض الملف")
- Bottom Navigation: الرئيسية / المفضلة / رسائلي / حملاتي / حسابي (5 تبويبات)

**نظام التصميم (سيُطبَّق على كل الصفحات):**
- إعداد RTL + خط عربي عبر `<link>` في `__root.tsx`
- توكنات OKLCH في `src/styles.css`: primary أزرق ملكي، accent بنفسجي فاتح، خلفية بيضاء ناصعة، نص داكن، حدود فاتحة جداً، ظلال ناعمة
- مكون BottomNav قابل لإعادة الاستخدام
- صور المؤثرين عبر `imagegen` (وجوه عربية متنوعة)

**الملفات:**
- `src/styles.css` — توكنات + RTL + خط
- `src/routes/__root.tsx` — link للخط، dir="rtl"، lang="ar"، meta عربي
- `src/routes/index.tsx` — صفحة اكتشف المؤثرين
- `src/components/BottomNav.tsx`
- `src/components/InfluencerCard.tsx`، `src/components/FeaturedInfluencerCard.tsx`
- `src/lib/mock-influencers.ts` — بيانات وهمية
- `src/assets/` — صور مولّدة للمؤثرين

### بعد موافقتك على الخطوة 1 سننتقل إلى:
2. صفحة الملف الشخصي للمؤثر (الصورة الثانية) — route `/influencer/$id`
3. صفحة إنشاء إعلان (3 خطوات wizard) — route `/campaign/new`
4. صفحة الدفع — route `/campaign/payment`
5. الصفحات المتبقية (المفضلة، الرسائل، حملاتي، حسابي)
6. ربط Lovable Cloud (مصادقة + قاعدة بيانات حقيقية) عند طلبك

- بعد كل صفحة سأتوقف لتجربتها قبل المتابعة
